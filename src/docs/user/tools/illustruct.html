Illustruct

Create molecular illustrations directly from structures open in ChimeraX. Start with Tools → Depiction → Illustruct or the command illustruct.

  1. Open a structure normally in ChimeraX. Choose all visible structures or one model above the preview; enable Selection only to use the current selection.
  2. Set colors in ChimeraX, orient the illustration, and adjust Simplification, Smoothing, and Outline.
  3. Choose component visibility in Components and output dimensions in Export.
  4. Use the footer buttons to export SVG, PDF, or PNG.

Drag the picture to rotate; Shift-drag to spin. The illustration and ChimeraX view rotate together around ChimeraX's current rotation center. A lighter preview updates during motion and automatically refines when motion stops. Exports wait until the final view is ready. Camera rotation leaves atom coordinates and model positions unchanged.

Disable Follow view above the preview to pause automatic updates from ChimeraX; Update captures the latest scene. Closing a structure in the illustration refreshes the preview even when following is paused. Dragging the picture and using illustration controls still update the preview when paused.

A small spinner beside Update indicates loading and refinement. The current illustration stays visible, and the preview and controls keep their positions.

Appearance, Components, and Export stay open. Scroll through the settings when space is limited, or drag the horizontal divider beneath the preview to give them more room. Settings remain compact and top-aligned, with a maximum width of 480 pixels; the export buttons stay visible. The divider position is saved with the ChimeraX session.

Appearance

Highlights & shadows overlays a solid lighter highlight near the upper contour and a solid darker shadow on the opposite side of each silhouette's unchanged component color. This single checkbox starts on; turn it off for single-color fills. DNA/RNA backbones remain flat. The effect retains continuous outlines, applies to preview and exports, and is saved with the session. SVG exports keep the base, shadow, and highlight as separate editable paths, with the outline on top and no gradients.

Highlight size and Shadow size independently adjust the width of each effect from 0–200%. Both default to 100%; 0% hides that effect and 200% doubles its width. The sliders update preview and export and save with the session. Turning Highlights & shadows off disables the sliders while retaining their values.

Highlights and shadows derive from each component's ChimeraX color through calibrated changes in lightness, saturation, and hue. Grays stay neutral.

The renderer combines broad, rounded atomic silhouettes with local depth and smooth vector outlines. The DNA/RNA setting applies to every nucleic acid component: Backbone is the default and draws simple, flat traces through sugar anchors without base tabs or inferred base pairs. Choose Silhouette for nucleic acid envelopes. Proteins, ligands, and ions remain silhouettes.

Set colors in ChimeraX; Illustruct follows them automatically while Follow view is enabled. Use Update after a change when following is paused. For example, color #1/B #4385BE changes Chain B in model #1. Protein chains automatically separate into components by residue color, retaining differently colored domains without a selection. A displayed ribbon supplies its residue's color; an atom-only residue uses the most common heavy-atom color in that residue.

Opacity, Simplification, and Smoothing use percentage sliders and apply to the whole illustration. The defaults are 50% Simplification and about 33% Smoothing. Lower Simplification retains more surface detail; higher values produce broader shapes. Try 50–100% Simplification and Smoothing for very rounded polymer envelopes. Ligands and ions remain compact.

Minimum piece size hides disconnected silhouette fragments below a chosen percentage of the largest visible piece's projected area in each component. This includes fragments separated by an overlapping component. It starts at 0% to keep all pieces; 5% hides pieces smaller than one twentieth of the largest, and 100% keeps only the largest pieces, including ties. Each component keeps its largest visible piece, preserving intentionally small whole components. DNA/RNA backbones are unchanged. The slider updates preview and exports and saves with the session.

Silhouette contours retain openings automatically. Set the width beside Outline; it uses output pixels in Pixel sizing and points in Print sizing. Tint outline to match derives darker outlines from component colors. Reducing opacity retains continuous outline curves.

Dashed colour boundaries makes borders between differently coloured regions of the same protein chain dashed. The outer silhouette and borders between separate chains remain solid. This option starts off and uses the source colours from ChimeraX. It also applies to differently colored manually selected regions within a chain. It requires Outline, applies to SVG, PDF, PNG and the preview, and is saved with the session.

Components

Proteins, DNA/RNA, Ligands, and Ions show or hide each type. New illustrations show only proteins; enable the other types as needed. Chains / Other are master switches. Switching a type or master off and back on preserves individual visibility choices. All switches apply to preview and export and save with your session. Counts show visible/total components.

The All types filter narrows the alphabetical list without changing the picture. Show / Hide change visibility for listed components. Show also enables the required type and master switches; other types retain their choices. Appearance settings are global, and depth determines drawing order automatically.

Protein residues of the same source color form a component within each chain, even when they are not adjacent in sequence. Differently colored residues form separate components automatically. Each nucleic acid chain and each ligand or ion is also a component. Single-atom nonpolymer residues are ions; larger nonpolymer residues are ligands. Classification uses the complete residue even when only some atoms are displayed or selected. Water and hydrogen are excluded.

Split selection adds a manual split between selected and unselected residues, independently of automatic protein color grouping. Select a region in ChimeraX, for example select /A:20-60, then enable this option. The split follows the current selection. Differently colored protein domains do not require this option or a selection.

Export

Choose Pixels or Print sizing. Pixels uses pixel dimensions and pixel outline widths. Print uses millimeter dimensions, point outline widths (1 pt = 1/72 inch), and DPI for PNG resolution. SVG and PDF preserve physical dimensions. The default canvas is 89 × 66.75 mm at 450 DPI with a 0.4 pt outline.

Margin adds space around fitted artwork; Transparent background controls the background. SVG and PDF remain editable vectors; PNG uses the requested pixel dimensions. Export buttons wait for the latest requested geometry.

Match camera uses ChimeraX's camera projection and viewport; otherwise the illustration uses an orthographic projection of the view direction and fits visible components to the output. Match camera suppresses extra margin. A different output aspect ratio adds space around the camera viewport. Lock frame keeps a fixed 2D frame and may crop the structure after rotations. Match camera takes precedence when both are enabled.

For scripted exports, use illustruct export filename.svg|pdf|png. Arguments use the same percentage scales as the panel and apply to that export only. For example, illustruct export ~/Desktop/figure.svg simplification 25 smoothing 45 changes the exported shape without changing the panel. Use atoms #1/A or atoms sel for an explicit source, or components nucleic for DNA/RNA only. See the command reference for sizing and framing.

Save your work

Save a normal ChimeraX .cxs session to retain illustration settings, component visibility, and underlying structures with their colors. SVG exports contain named component groups and camera metadata. No data is uploaded.

Scope and limitations

This is a stylized atomic representation, not a solvent-accessible surface or a reproduction of cartoon thickness. Gaussian envelopes use native default atomic radii, independently of display radius overrides. Visible scope includes displayed atoms and residues represented by ribbons. Molecular surfaces, maps, labels, and arbitrary drawings are not converted. Selection scope can include hidden atoms. Displayed biological assembly instances are included.

Automatic splitting by residue color currently applies to proteins. DNA/RNA retains one representative source color per component; mixed-color nucleic components use their most common captured color. Split selection can still separate a selected nucleic region manually. Atom colors within one protein residue are reduced to a single source color.

Clipping planes are not applied. Stereo uses the central camera; specialized panoramic cameras fall back with a warning. Silhouettes are extracted from a bounded visibility grid, so very small details may be simplified. Increasing simplification may close narrow openings. Flat backbones use component depth ordering.

Install and update

Download the .whl file from GitHub Releases. If no release is listed yet, use a locally built or maintainer-supplied wheel. With ChimeraX's working folder set to the folder containing the wheel, run toolshed install illustruct-0.1.0-py3-none-any.whl. To update, install the newer wheel and restart ChimeraX. Updates are manual.

Tested with ChimeraX 1.10 on Apple silicon Macs. Command reference.
