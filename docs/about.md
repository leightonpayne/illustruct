# About

Illustruct is
[MIT licensed](https://github.com/leightonpayne/illustruct/blob/main/LICENSE).

Report problems on [GitHub](https://github.com/leightonpayne/illustruct/issues).
Include your ChimeraX version, operating system, and a small reproducible
example. See [Development](development.md#contribute) to contribute.

## Credits

- [Johannes Kühn](https://www.linkedin.com/in/johannes-a-kuehn/) developed a
  prototype tool for stylized molecular representations, on which Illustruct was
  based.
- [UCSF ChimeraX](https://www.cgl.ucsf.edu/chimerax/) provides the molecular
  data, scene, and native rendering infrastructure. Illustruct is an independent
  extension, not affiliated with or endorsed by UCSF.
- The homepage illustration and figure workflow use
  [PDB 9B7D, the ThsB–Tad3 complex](https://www.rcsb.org/structure/9B7D).

ChimeraX, dependencies, and external assets retain their own licenses.
